# NovaTour

Site vitrine officiel de NovaTour, plateforme de découverte de lieux en Occitanie grâce aux visites immersives à 360°.

## Development

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```

## Built with

- TanStack Start
- TypeScript
- React
- Tailwind CSS

## Deployment

Deployed on Vercel (nitro preset `vercel`, configured in `vite.config.ts`). Every push to a branch with an open pull request gets its own preview deployment.
